# DocMind AI 🧠

An AI-powered workspace for students, developers, and office teams.

## Planned Features
- [ ] AI Chat Assistant
- [ ] Chat with PDF
- [ ] Document Summarizer
- [ ] AI Email Generator
- [ ] Resume Checker
- [ ] Spam Detector
- [ ] User accounts & chat history

## Tech Stack
- Frontend: React
- Backend: Java + Spring Boot
- Database: MySQL
- AI: LLM API
